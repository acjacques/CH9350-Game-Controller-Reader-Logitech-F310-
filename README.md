# CH9350-Game-Controller-Reader-Gamepad Logitech-F310-
The code allow to read the Gamepad Game Controller like Logitech F310  using the CH9350 Module. Output is thru SerialPort
Code was write for Arduino Nano + SoftwareSerial but could be easely ported to other processors
Module CH9350 is a cheap USB HID translator capturing events and sending the frames to serial port.
Module has 2 USB ports that could operate simultaneously. May also read mouse and keyboards.

Code developed by acjacques. November 2026 . contact:  acj@infolink.com.br  Whatsapp: 55 21 992148116

The CH9350 module is highly versatile and can be configured for bidirectional operation as either a USB host or a USB device. Two such modules can be linked together to function as an extension bridge, transmitting data via a serial port. These features—as well as the ability to read or emulate a mouse and keyboard—are not covered by the software discussed here.
